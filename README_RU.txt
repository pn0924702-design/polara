POLARA — локальный поисковый прототип
=====================================

КАК ЗАПУСТИТЬ
1. Убедись, что Python установлен.
2. Распакуй весь архив в обычную папку.
3. Дважды щёлкни по start.bat.
4. Не закрывай чёрное окно.
5. В браузере открой: http://127.0.0.1:8765

КАК ПОПРОБОВАТЬ ПОИСК
1. В поле «Добавить сайт в индекс» введи https://example.com/
2. Нажми «Индексировать» и дождись завершения.
3. В верхнем поиске попробуй слова из содержимого сайта.

ВАЖНО
- Это учебный прототип, который работает на этом компьютере.
- Он не индексирует весь интернет и не является готовым коммерческим поисковиком.
- Индекс хранится в index.json в этой папке.
- Для остановки нажми Ctrl+C в чёрном окне.
- Индексатор ограничен 20 страницами одного домена за запуск, делает паузы
  между запросами и старается соблюдать robots.txt сайта.
- Некоторые сайты запрещают автоматический сбор данных или могут не открываться.
- Не публикуй локальный сервер в интернете без отдельной настройки безопасности.

ЕСЛИ НЕ ЗАПУСКАЕТСЯ
Проверь, что Python установлен. Если Windows не находит Python, переустанови
его с официального сайта https://www.python.org/downloads/windows/ и отметь
пункт Add Python to PATH, если он показан. Затем запусти start.bat снова.
