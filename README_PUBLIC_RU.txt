POLARA — заготовка для публикации веб-демо

ЧТО ЭТО
Эта сборка умеет запускаться на веб-хостинге (слушает PORT и 0.0.0.0).
Публичное индексирование отключено по умолчанию: открытый краулер без
защиты может быть использован злоумышленниками. Демо ищет только по
уже имеющимся страницам в index.json. Это НЕ поиск по всему интернету.

КАК ОПУБЛИКОВАТЬ (нужен аккаунт Render и GitHub)
1. Создай репозиторий на GitHub и загрузи в него содержимое этой папки.
2. В Render выбери New > Blueprint, подключи GitHub-репозиторий.
3. Render прочитает render.yaml и создаст веб-сервис.
4. После успешного Deploy открой выданный Render адрес — он будет публичным.

ВАЖНО
- Я не могу создать аккаунты, подключить GitHub или нажать Deploy от твоего имени.
- Бесплатный хостинг может засыпать, иметь лимиты и не гарантирует постоянное
  хранение index.json. Для серьёзного публичного сервиса нужен подходящий тариф,
  постоянное хранилище, мониторинг и защита.
- Не включай POLARA_ENABLE_CRAWL=1 на публичном сервере без защиты API,
  ограничений частоты, очереди задач и постоянного хранилища.
- Даже после публикации текущая версия индексирует лишь малое число страниц;
  для поиска по вебу нужно отдельно подключить поисковый API или строить
  полноценный краулер и индекс.
